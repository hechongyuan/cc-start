# 🍅 桌面番茄钟挂件

一个悬浮在桌面上的透明番茄钟小挂件（Python + tkinter，无需安装任何第三方库）。

## 启动方式

- 双击 **`启动番茄钟.bat`**（推荐，无黑色控制台窗口）
- 或命令行运行：`python pomodoro_widget.py`

## 使用说明

| 操作 | 说明 |
|------|------|
| ▶ / ⏸ | 开始 / 暂停 |
| ↺ | 重置当前倒计时 |
| ⚙ | 打开 / 关闭时长设置（1~120 分钟） |
| ✕ | 退出挂件 |
| 右键 | 弹出菜单，可退出 |
| 拖动 | 按住卡片空白处可随意移动 |

- 默认 **25 分钟专注 + 5 分钟休息**，时间到自动切换并播放提示音 + 弹窗通知。
- 挂件置顶显示，可拖动到屏幕任何位置。
- 点 ✕ 或右键菜单退出；再次使用双击 bat 即可。

## 常见问题

- **设置面板打不开 / 数字改不动**：直接点击数字框上下的箭头，或用键盘输入后回车即可。
- **提示音没响**：确认系统音量正常（提示音用的是系统蜂鸣）。
- **挂件被别的窗口挡住**：它就是置顶的，如果还是被挡住，拖动换个位置即可。
